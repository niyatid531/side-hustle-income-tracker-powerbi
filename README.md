# Side-Hustle Income Tracker + Smart Investment Planner
A Power BI dashboard to track side-hustle income and plan smarter investments, with separate **User** and **Admin** views.
Built as part of the Data Science & Analytics minor.

## Overview
Students and young earners often juggle multiple side-hustle income streams with no clear view of earnings or where to invest them. This dashboard brings income tracking and investment planning into one interactive report.

## Features

### User Dashboard
- Income tracking across side-hustle sources
- Monthly and category-wise earnings trends
- Smart investment planner to allocate savings
- Interactive filters and slicers

### Admin Dashboard
- Consolidated view of all users' income and activity
- Performance and trend monitoring
- Key insights for decision-making

## Tech Stack

| Area | Tools |
|------|-------|
| Visualization | Power BI Desktop |
| Calculations | DAX |
| Data Modeling | Power Query, Relationships |
| Data Source | Excel / CSV |


## How to Use

1. Download `Side-Hustle-Income-Tracker.pbix` from this repository.
2. Open it in **Power BI Desktop**.
3. Use the slicers and page navigation to explore the User and Admin views.
